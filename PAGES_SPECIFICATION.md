## 1. Overview & Tier Summary

This document specifies all website pages, interactive views, and report outputs across the three evolution stages of the system:
1. **Tier 1: Prototype (Hackathon Demo Version)** — Lean, high-impact 5-page flow with automated A4 PDF generation.
2. **Tier 2: Minimum Viable Product (MVP / Pilot Lab Version)** — Complete 19-test catalogue, equipment & standard weights management, and instrument import.
3. **Tier 3: Full Enterprise Production Version (Accredited Metrology Lab)** — Full ISO/IEC 17025 compliance, immutable audit logging, multi-tenant lab hierarchy, and PKI digital signatures.

## 2. Tier 1: Prototype (Hackathon Demo Version)

### Target Goal
Deliver a fast, authoritative, zero-friction 3-minute demonstration proving that manual Excel workbooks (such as DELTA’s `DTPR76`) can be replaced by automated data entry, real-time error curves, and one-click PDF generation against Supabase PostgreSQL.

### Prototype Pages Breakdown

| # | Page / Route | Purpose & Core Features | Status |
|---|---|---|:---:|
| **1** | **Main Dashboard**<br>`#/projects` | • High-level overview of active pattern evaluation campaigns.<br>• Search by Task #, Report #, Manufacturer, or Model.<br>• Filter by status (`draft`, `in_progress`, `completed`).<br>• High-performance single-query database rollups (**118ms** from Supabase).<br>• **"+ New Examination"** primary call-to-action. | **DONE** |
| **2** | **Examination Creation Wizard**<br>`#/projects/new` | • **Step 1:** Project metadata (Task #, Report #, standard, manufacturer).<br>• **Step 2:** Scale specification ($Max, Min, e, d, n$, accuracy class, zero/tare).<br>• **Step 3:** Automatic reference weight generation spanning $Min$ to $Max$. | **DONE** |
| **3** | **Project Workspace Hub**<br>`#/projects/:id` | • Project summary and instrument models list.<br>• Digital approval signature block (Lead Metrologist & QA sign-off).<br>• Direct triggers for *Conformity Checklist* and *Generate Report*. | **DONE** |
| **4** | **Pattern Conformity Checklist**<br>`#/projects/:id/checklist` | • 15 seeded representative EN 45501 clauses (markings, zero-setting, tare).<br>• `Existent / Non-Existent` and `Pass / Fail / NA` toggles.<br>• Remarks and test-run evidence linkage. | **DONE** |
| **5** | **Test Data Entry & Live Charts**<br>`#/models/:id/tests/:code` | • Dedicated forms with real-time error arithmetic ($E = I + 0.5e - L$, $E_c = E - E_0$).<br>• Dynamic SVG error curves with step-function MPE envelopes.<br>• Implemented: *Initial Intrinsic Error (`INTRINSIC`)*, *Repeatability (`REP`)*, *Eccentricity (`ECC`)* with interactive pan diagram, *Temperature (`T1`, `T2`)*, *ESD (`EMC_ESD`)*, *Span Stability (`SPAN`)*.<br>• Evidence & photos upload tab. | **DONE** |
| **6** | **Generated Reports (Stored PDFs Archive)**<br>`#/reports` | • **Digital vault of stored PDF & HTML reports** generated by the system.<br>• Immutable, timestamped rows preserving historical revisions.<br>• Filter by Report #, Task #, Manufacturer, or Verdict.<br>• Direct **"Download PDF"** and **"View HTML"** buttons. | **TO BE COMPLETED** |
| **7** | **Test Run History & Log**<br>`#/test-history` | • Unified chronological audit log of all individual test runs executed across models.<br>• Filter by test type, operator name, date range, and verdict.<br>• 1-click jump back to the interactive test workspace. | **DONE** |
| **8** | **Official A4 Report Engine**<br>`/api/projects/:id/reports/preview` | • Automated 8-sheet document matching official laboratory standards (Cover, Checklist, Summary, Instrument Info, Standards, Photos, Test Curves, Signatures). | **DONE** |

## 3. Tier 2: Minimum Viable Product (MVP / Pilot Lab Version)

### Target Goal
Support complete non-automatic weighing instrument type examinations in a pilot calibration/testing laboratory with multi-model families, full OIML R76 test catalogue coverage, reference standards inventory, and direct digital scale data capture.

### MVP Pages & Capabilities

| # | Page / Route | Description & Functional Scope | Status |
|---|---|---|:---:|
| **1** | **Main Dashboard & Lab KPIs**<br>`#/dashboard` | • Live KPI cards: Active Projects, Overall Lab Pass Rate, Pending Sign-offs.<br>• Quick filters for upcoming calibration deadlines and incomplete test runs. | **TO BE COMPLETED** |
| **2** | **Multi-Model Family Wizard**<br>`#/projects/new` | • Multi-model instrument family setup (e.g. testing NHB150, NHB1500, and NHB6000 in one campaign with shared manufacturer profile). | **DONE (Schema ready)** |
| **3** | **Full OIML R76 Test Suite (All 19 Tests)**<br>`#/models/:id/tests/:code` | • `T3`, `T4`, `EMC_BURST`, `EQUIL`, `ZERO_CREEP`, `TARE`, `VOLT` and `DAMP1` now implemented (the last three reuse `weighing_performance` with zero code changes). `EMC_RADIATED` is honestly a different shape (frequency sweep, new form kind) and stays a declaration. Remaining 4 test forms: *Tilting (`TILT`)*, *Warm-up Time (`WARMUP`)*, *Radiated Fields (`EMC_RADIATED`)*, *Discrimination (`DISCRIM`)*. | **PARTIALLY DONE (15/19 implemented)** |
| **4** | **Calibrated Weights & Equipment Master**<br>`#/equipment` | • Master inventory of reference standard weight sets (Class E2, F1, M1).<br>• Track calibration certificates, uncertainty values, and expiry dates.<br>• Auto-link valid standard weights to test runs for ISO 17025 traceability. | **PLANNED** |
| **5** | **Direct Instrument Data Ingestion**<br>`#/models/:id/tests/:code/import` | • Upload CSV / Excel readings exported directly from digital balances and load cells.<br>• Direct RS232 / USB serial stream data capture for continuous trial logging. | **PLANNED** |
| **6** | **Metrologist Digital Signature Certificates**<br>`#/projects/:id/sign` | • Password/PIN authenticated digital signature capture with SHA-256 integrity hash sealing the examination state upon completion. | **PLANNED** |
| **7** | **Stored PDF & DOCX Export Vault**<br>`#/reports` | • PDF generation with embedded vector charts.<br>• Editable Microsoft Word (`.docx`) template export for custom national laboratory annexes. | **PARTIALLY DONE (PDF Done, DOCX Planned)** |
